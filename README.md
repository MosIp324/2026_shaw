# Shaw Prize 2026 展示網站

## 專案簡介
本專案為一個以邵逸夫獎為主題的靜態展示網站，使用 HTML / CSS / JavaScript 建立，適合部署於展示屏、展覽機或 kiosk 瀏覽器中使用。

主要目的：
- 展示邵逸夫獎基金會簡介
- 展示理事會與評審委員會資訊
- 展示各學科遴選委員會內容
- 提供中英繁簡語言切換
- 以 16:9 版面進行展示，適合大型螢幕

主要入口：
- index.html：開場介紹頁
- Main/Foundation/index.html：主內容入口頁

---

## 執行方式

### 方式一：直接打開
直接在瀏覽器中打開：
- index.html

這會進入開場頁，點擊後再進入主內容目錄。

### 方式二：本機伺服器（建議）
在專案根目錄執行：

```bash
cd 2026_shaw
python -m http.server 8000
```

之後於瀏覽器開啟：

```text
http://localhost:8000/
```

建議使用此方式，因為靜態頁面在相對路徑與資源載入上較穩定。

## 網站內容邏輯

### 1. 頁面導覽
網站以「基金會」為主要入口，之後依序導向：
- The Shaw Prize Foundation
- Council
- Board of Adjudicators
- Selection Committees

### 2. 語言切換
每個頁面內均有語言切換按鈕，通常包括：
- ENG
- 繁
- 简

切換邏輯主要在頁面腳本中由 `translations` 物件控制，透過 `data-i18n` 屬性更新內容文字。

### 3. 展示版面
此網站使用固定比例的 16:9 版型設計，適合電腦螢幕、展示屏或投影設備的使用情境。

## 內容維護方式

### 更新文字內容
若需要修改標題、導覽名稱、說明文字，優先檢查以下位置：
- HTML 內的文本內容
- `data-i18n` 屬性
- 每頁腳本中的 `translations` 物件

### 更新圖片
圖片通常位於：
- 各頁面同層資料夾
- `img/` 目錄
- 主內容區的對應資源檔

當替換圖片時，請同步確認：
- `src` 路徑正確
- `alt` 文案合理
- 版面不會被裁切或變形

### 更新連結
部分頁面是用相對路徑連到其他 HTML 檔案，若檔名或資料夾名稱變更，必須同步更新連結。
